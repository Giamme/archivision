`archivision repo --check` checks a saved map against the code for CI: it writes nothing and exits 1 when a source file is placed by no rule of the map or the map names code that is gone (a glob that matches nothing, a part or block with no files, a walkthrough step or table model that no longer exists), with GitHub Actions annotations; with no saved map it exits 2.
